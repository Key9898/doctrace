# Impl 23 — 350px matching step UI

Source: this batch (2026-08-31). Same day as Impl 18–22, so the session file uses `-impl-23`.

Matching is a one-step task pane: Select, Import, Match, Review. Free jump; controller gates (identity, empty selection) stay. Hero, 4-stat grid, `max-w-6xl`, two-column grid, and the ABOUT/project marketing block are gone.

Viewer + Snip sit in a dock on every matching step. Default collapsed. Expand follows Zustand `viewer` (cell click, import preview, Results focus), not `focusEvidenceViewer` alone. `"step-viewer"` is not a step id. Collapsed dock unmounts `ViewerPane` so the 300px canvas is not in the flow.

Browser matching column is `max-w-[350px]` when `officeAvailable` is false. Excel (`officeAvailable`) fills the pane. Engagements is not capped. Do not key this split off `.dt-excel-host` — `office.js` loads in Browser Preview too.

Out of scope: matching scores, evidence/snip Custom XML, ISA log, identity persistence, leftover `src/components/`, EngagementManager redesign.
